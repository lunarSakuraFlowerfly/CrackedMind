# 波纹效果设置指南

## 问题与解决方案

如果您发现睡眠时只有屏幕变黑，但没有波纹效果，最常见的原因是**材质引用问题**。以下是解决方案：

## 正确设置步骤

### 1. 设置波纹材质

**方法一：使用预制材质**
- 在Project窗口中找到 `Assets/Resources/Materials/RippleMaterial.mat`
- 将此材质直接拖拽到以下位置：
  - SleepWakeEffect组件的 `m_RippleMaterial` 字段
  - RipplePostProcess组件的 `m_DirectMaterial` 字段

**方法二：手动创建材质**
- 在Project窗口中右键 → Create → Material
- 在Inspector中，将shader设置为"Custom/Ripple"
- 设置以下属性：
  - _RippleStrength: 0.5
  - _RippleSpeed: 5
  - _RippleSize: 10
  - _EffectEnabled: 1

### 2. 设置摄像机

1. 选择主摄像机（通常标记为MainCamera）
2. 添加RipplePostProcess组件：
   - Add Component → Scripts → InteractionSystem → Items → Bed → RipplePostProcess
3. 在RipplePostProcess组件中：
   - 将创建好的Ripple材质拖拽到 `m_DirectMaterial` 字段
   - 确保 `m_DebugMode` 选项勾选

### 3. 设置床对象

1. 选择您的床游戏对象
2. 确保它有SleepWakeEffect组件
3. 在SleepWakeEffect组件中：
   - 将相同的Ripple材质拖拽到 `m_RippleMaterial` 字段
   - 确保黑屏UI已设置（`m_BlackoutImage`字段）或启用 `m_AutoCreateUI`
   - 如果有梦境场景，确保在 `m_DreamSceneName` 中正确填写

### 4. 连接BedInteractable与SleepWakeEffect

1. 确保床对象上有BedInteractable组件
2. 在BedInteractable组件中：
   - 将SleepWakeEffect组件引用到 `m_SleepEffect` 字段

## 常见问题排查

### 波纹效果不显示

**检查控制台日志**：
- 红色错误信息可能会指示问题所在
- 特别关注材质、shader相关的错误

**检查材质设置**：
- 运行时打开Inspector，查看材质是否显示为"None"
- 如果材质为None但参数在变化，说明材质引用有问题

**手动测试效果**：
- 运行游戏后，选择主摄像机
- 在RipplePostProcess组件上点击"Test"按钮（如果添加了测试按钮）
- 或者按"T"键测试效果（需要在Inspector中勾选调试模式）

### 材质显示正常但效果不可见

**检查shader设置**：
- 确保shader使用的是"Custom/Ripple"
- 检查_EffectEnabled参数是否为1

**检查渲染设置**：
- 确保摄像机已启用
- 确保后处理栈顺序正确（如果使用多个后处理）

## 提示

- 对于重要的设置，始终保留一个备份
- 使用调试模式查看详细日志
- 如果一切设置正确但效果仍不显示，尝试重新导入shader文件

希望这个指南能帮助您解决波纹效果的问题！
