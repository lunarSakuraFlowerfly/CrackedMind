# 睡眠与梦境系统

## 系统概述

睡眠与梦境系统实现了玩家与床的交互功能，支持以下特性：
- 玩家与床交互，触发睡眠行为
- 睡眠时的波纹和淡入淡出视觉效果
- 现实世界与梦境世界的场景切换
- 游戏内时间/天数的推进
- 基于条件的梦境退出机制
- 可扩展的睡眠条件检查系统

## 组件说明

### 1. BedInteractable

床铺交互组件，负责处理玩家与床的交互逻辑。

**主要功能**:
- 显示睡觉提示
- 处理首次交互对话
- 检查睡眠条件
- 触发睡眠序列

**关键属性**:
- `m_InteractPrompt`: 交互提示文本
- `m_FirstInteractionDialogue`: 首次交互对话数据
- `m_CannotSleepDialogue`: 无法睡觉时的对话数据
- `m_SleepTransitionDuration`: 睡眠过渡动画时长

### 2. SleepWakeEffect

睡眠与唤醒特效组件，负责处理场景切换和视觉效果。

**主要功能**:
- 波纹视觉效果
- 屏幕淡入淡出
- 场景切换
- 玩家位置重置

**关键属性**:
- `m_BlackoutImage`: 黑屏过渡图像
- `m_RippleMaterial`: 波纹效果材质
- `m_DreamSceneName`: 梦境场景名称
- `m_RealWorldSceneName`: 现实场景名称
- `m_BedPosition`: 床位置（醒来返回点）

### 3. DreamExit

梦境退出控制器，定义从梦境醒来的条件。

**主要功能**:
- 测试按键触发退出
- 自定义醒来条件
- 退出事件通知

**关键属性**:
- `m_EnableTestKey`: 是否启用测试按键
- `m_TestExitKey`: 测试用退出按键（默认为1）

### 4. SleepConditionChecker

睡眠条件检查器，用于管理睡眠条件。

**主要功能**:
- 注册/注销睡眠条件检查器
- 检查是否满足睡眠条件
- 获取无法睡觉的原因

### 5. QuestSleepCondition

基于任务的睡眠条件示例。

**主要功能**:
- 基于任务完成情况判断是否可以睡觉
- 提供无法睡觉的原因说明

## 使用指南

### 基本设置

1. **UI设置**
   - 创建Canvas对象并添加全屏黑色Image
   - 设置Image的初始Alpha为0
   - 将此Image赋值给SleepWakeEffect的m_BlackoutImage字段

2. **波纹材质设置**
   - 创建使用RippleEffect着色器的材质
   - 调整Ripple Strength参数到合适值
   - 将此材质赋值给SleepWakeEffect的m_RippleMaterial字段

3. **场景设置**
   - 在SleepWakeEffect中设置梦境和现实场景名称
   - 设置床的位置引用，用于玩家醒来后的位置重置

### 配置睡眠条件

1. **使用内置条件检查器**
   ```csharp
   // 创建睡眠条件并注册
   QuestSleepCondition questCondition = gameObject.AddComponent<QuestSleepCondition>();
   SleepConditionChecker.Instance.RegisterCondition(questCondition);
   ```

2. **自定义醒来条件**
   ```csharp
   // 在脚本中添加自定义醒来条件
   DreamExit dreamExit = FindObjectOfType<DreamExit>();
   dreamExit.AddWakeCondition(() => {
       // 返回true表示可以醒来
       return PlayerInventory.HasItem("梦境钥匙");
   });
   ```

### 触发睡眠和唤醒

1. **触发睡眠**
   ```csharp
   // 在床铺交互时
   SleepWakeEffect sleepEffect = FindObjectOfType<SleepWakeEffect>();
   sleepEffect.StartSleep();
   ```

2. **触发唤醒**
   ```csharp
   // 在满足醒来条件时
   DreamExit dreamExit = FindObjectOfType<DreamExit>();
   dreamExit.ExitDream();
   ```

## 示例流程

典型的睡眠与梦境交互流程：

1. 玩家与床交互
2. 系统检查玩家是否可以睡觉
3. 开始波纹效果和黑屏过渡
4. 切换到梦境场景
5. 玩家在梦境中探索
6. 达成醒来条件（如按1键测试）
7. 开始波纹效果和黑屏过渡
8. 切换回现实场景，玩家位置重置到床上
9. 游戏天数+1

## 扩展建议

1. **添加睡眠效果**
   - 恢复角色体力/生命值
   - 重置场景状态
   - 触发特定事件或NPC对话

2. **增强梦境体验**
   - 添加独特的梦境滤镜效果
   - 创建特殊的梦境专属敌人/NPC
   - 设计独特的梦境解谜机制

3. **与其他系统集成**
   - 日记系统记录梦境内容
   - 梦境收集系统
   - 根据现实世界事件影响梦境内容

## 注意事项

1. 确保SleepWakeEffect组件在场景切换后仍然存在（可使用DontDestroyOnLoad）
2. 检查场景名称设置是否正确且已添加到构建设置中
3. 避免在过渡效果过程中允许玩家输入
4. 注意正确设置材质和UI引用，避免空引用异常
